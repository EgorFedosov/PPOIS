# Minesweeper Online

Desktop-приложение на Python по варианту 15 (Minesweeper): соло-режим и онлайн-режим на двоих с ограничением по времени.

## Реализация по ТЗ

- Событийная архитектура на `pygame`.
- UI построен на `pygame_gui` (меню, справка, рекорды, диалог рекорда).
- Логика игры вынесена в отдельный модуль `src/core/minesweeper.py`.
- Ограничение по времени для каждого уровня.
- Онлайн-режим для 2 игроков (общее поле, синхронные действия).
- Таблица рекордов и ввод имени при новом лучшем результате.
- Звуки и фоновая музыка через `pygame.mixer`.
- Настройки и данные во внешних JSON-файлах.
- Документация в Markdown.

## Зависимости

- Python 3.11+
- `pygame-ce`
- `pygame-gui`

Установка:

```bash
pip install -r requirements.txt
```

## Запуск

1. Запустить сервер:

```bash
python run_server.py
```

2. Запустить один или два клиента:

```bash
python run_client.py
```

Для онлайн-игры подключите два клиента.

## Управление

- ЛКМ: открыть клетку
- ПКМ: поставить/снять флаг
- `R`: новая игра
- `Esc`: вернуться в меню

## Конфиги

- `config/app.json` — окно, FPS, цвета, громкость
- `config/levels.json` — размеры поля, количество мин, лимит времени
- `config/network.json` — host, port, размер лобби
- `config/help.json` — текст справки
- `data/records.json` — таблица рекордов
